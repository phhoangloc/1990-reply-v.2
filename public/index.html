Phòng đã sẵn sàng
Chọn ROM để bắt đầu chơi, hoặc kéo-thả file .nes (hoặc .zip có chứa ROM) vào khung này. Bạn bè vào phòng sẽ nhận game tự động.

Phím điều khiển & mẹo
Di chuyển ←↑↓→ hoặc WASD
Nút A / B X hoặc K / Z hoặc J
Start / Select Enter / Shift hoặc Backspace
Tua nhanh (giữ) Space
Tạm dừng / Reset P / R
Tắt tiếng / Toàn màn hình M / F
Tay cầm Hỗ trợ tay cầm chuẩn (Xbox/PlayStation…), có thể gán nút trong "Phím điều khiển"
Lưu game Game có pin (battery save) được lưu tự động trong trình duyệt

Mapper hỗ trợ: 0 (NROM), 1 (MMC1), 2 (UxROM), 3 (CNROM), 4 (MMC3), 7 (AxROM), 11, 66 (GxROM), 71 — đủ chạy phần lớn thư viện game NES.

Ứng dụng không kèm ROM. Hãy dùng ROM bạn sở hữu hợp pháp.
